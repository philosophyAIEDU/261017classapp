# Firebase 연결하기 (강사님·수강생이 각자 기기에서 함께 쓰기)

Firebase를 연결하면 데이터가 온라인에 저장돼서, 강사님 노트북에서 만든 과제가 수강생 휴대폰에 보이고
수강생이 낸 글이 강사님 대시보드에 모입니다. 로그인도 진짜로 동작해요.

- 강사님: **Google 계정**으로 로그인
- 수강생: **클래스 코드 + 번호 + 이름 + 비밀번호**로 가입 → 강사님이 승인 (실제 이메일·전화번호는 받지 않아요)

> 이 앱에는 `classapp-c569a` 프로젝트 설정이 이미 들어 있어요. (`src/config/firebaseConfig.ts`)
> 다른 Firebase 프로젝트를 쓰려면 그 파일의 값을 내 프로젝트 값으로 바꾸세요.

---

## 1. Firebase 콘솔에서 할 일 (10분)

**https://console.firebase.google.com** → 내 프로젝트를 엽니다.

### ① 로그인 방법 2개 켜기
1. 왼쪽 메뉴 **빌드 → Authentication → 로그인 방법(Sign-in method)** 탭
2. **Google** → 사용 설정 (이미 켜셨다면 그대로)
3. **이메일/비밀번호(Email/Password)** → **사용 설정** 스위치 켜기 → 저장
   - 수강생 로그인에 필요해요. 아래 "이메일 링크(비밀번호 없는 로그인)"는 켜지 않아도 됩니다.

### ② 승인된 도메인 추가
같은 화면의 **설정(Settings) → 승인된 도메인(Authorized domains)** → **도메인 추가**
- Netlify 주소: 예) `rainbow-english.netlify.app`
- 내 도메인을 연결했다면 그 주소도: 예) `philosophyaiedu.com`
- `localhost`는 처음부터 들어 있어요.

> 이걸 빠뜨리면 Google 로그인 때 "이 주소에서는 로그인이 아직 허용되지 않았어요"가 나옵니다.

### ③ 보안 규칙 붙여 넣기 (가장 중요!)
1. 왼쪽 메뉴 **빌드 → Firestore Database → 규칙(Rules)** 탭
2. 안에 있는 내용을 **모두 지우고**, 이 앱의 `firestore.rules` 파일 내용을 **통째로 복사해 붙여 넣기**
3. **게시(Publish)** 클릭

> 규칙을 붙여 넣지 않으면 앱이 "권한이 없어요"라며 동작하지 않거나, 반대로 아무나 데이터를 볼 수 있게 돼요.

### ④ (사진) Storage는 필요 없어요
루틴 인증 사진은 자동으로 작게 줄여서(약 300KB 이하) Firestore에 함께 저장합니다.
유료(Blaze) 요금제가 필요한 Storage를 켜지 않아도 돼요.

## 2. Netlify 환경변수 넣기

Netlify → 내 프로젝트 → **Project configuration(Site configuration) → Environment variables → Add a variable**

| 이름 | 값 | 꼭? | 설명 |
| --- | --- | --- | --- |
| `VITE_DATA_MODE` | `firebase` | ✅ | Firebase에 저장하기 (이 값이 없으면 브라우저 저장 모드) |
| `GEMINI_API_KEY` | `AIza…` 내 Gemini 키 | 추천 | 수강생 휴대폰에서도 진짜 AI가 동작하게 하는 서버 키 |
| `TEACHER_EMAILS` | 내 Google 이메일 | 추천 | 이 이메일로 로그인한 강사님의 클래스만 서버 키를 쓸 수 있어요. 여러 명이면 쉼표로: `a@gmail.com, b@gmail.com` |
| `FIREBASE_SERVICE_ACCOUNT` | 서비스 계정 키(JSON) | 선택 | 수강생 **비밀번호 초기화** 기능에 필요 (아래 3번) |

> 🔐 `GEMINI_API_KEY`, `FIREBASE_SERVICE_ACCOUNT`는 **절대 `VITE_`로 시작하는 이름에 넣지 마세요.**
> 환경변수를 바꾼 뒤에는 **Deploys → Trigger deploy → Deploy site**를 눌러야 반영돼요.

### 서버 키는 안전한가요?
Firebase 모드에서는 AI 요청마다 서버가 다음을 확인합니다.
1. **로그인 토큰**이 진짜인지 (없거나 가짜면 거절)
2. 그 사람이 **우리 클래스의 승인된 구성원**인지
3. 그 클래스의 강사님 이메일이 **`TEACHER_EMAILS`에 있는지** (없으면 서버 키를 쓸 수 없어요)
4. **Gemini 무료 티어 보호**: 앱 전체가 1분에 8번, 하루에 200번을 넘으면 AI를 부르지 않아요. (`ai.freeTier`)
5. 수강생이면 **하루 사용 횟수**: AI 전체 20번, 그중 튜터 질문 15번 (`src/config/appConfig.ts`의 `ai.dailyAiLimit`, `ai.tutorDailyLimit`)

그래서 배포 주소를 알아도, 승인받지 않은 사람은 서버 키를 쓸 수 없어요.
`TEACHER_EMAILS`를 비워 두면 서버 키는 아무도 못 쓰고, 각자 **AI 설정**에 자기 키를 넣은 기기에서만 진짜 AI가 동작합니다.

## 3. (선택) 비밀번호 초기화 켜기 — 서비스 계정 키

수강생이 비밀번호를 잊으면 로그인 화면의 **"비밀번호를 잊었어요"**로 요청하고,
강사님이 **구성원 → 임시 비밀번호 만들기**를 누르면 6자리 임시 비밀번호가 나옵니다.
남의 비밀번호를 바꾸는 일이라 **관리자 키**가 필요해요.

1. Firebase 콘솔 → ⚙️ **프로젝트 설정 → 서비스 계정** 탭
2. **새 비공개 키 생성** → **키 생성** → `.json` 파일이 내려받아져요
3. 그 파일을 메모장으로 열어 **내용 전체**를 복사
4. Netlify 환경변수 `FIREBASE_SERVICE_ACCOUNT`에 붙여 넣기 → 다시 배포

> ⚠️ 이 파일은 **프로젝트 전체를 관리할 수 있는 열쇠**예요. GitHub에 올리거나 다른 사람에게 보내지 마세요.
> 잃어버렸거나 퍼졌다면 같은 화면에서 그 키를 삭제하고 새로 만드세요.

## 4. 처음 써 보기 (확인 순서)

1. 배포 주소 → **Google로 시작하기** → 내 Google 계정 선택
2. **클래스 만들기** (예: `중급 영어 A반`) → 입장 QR 화면이 나와요
3. 휴대폰으로 QR을 찍어 **수강생으로 가입** (비밀번호는 6자 이상)
4. 노트북 **구성원** 메뉴 → 가입 대기에서 **승인**
5. **과제 관리 → 새 과제** → 휴대폰에서 과제를 열어 글 제출 → AI 피드백 확인
6. 대시보드에 제출률이 올라가면 성공! 🎉

### 내 컴퓨터에서 Firebase 모드로 실행하기
`.env` 파일에 `VITE_DATA_MODE=firebase`를 넣고 `npm run dev:ai` → http://localhost:8888

## 문제가 생겼을 때

| 화면에 나온 말 | 해결 |
| --- | --- |
| 이 주소에서는 로그인이 아직 허용되지 않았어요 | 1-② 승인된 도메인에 지금 주소 추가 |
| 이 로그인 방법이 아직 켜져 있지 않아요 | 1-① 이메일/비밀번호 사용 설정 |
| 이 내용을 볼 수 있는 권한이 없어요 | 1-③ 규칙을 붙여 넣고 **게시**했는지 확인. 수강생이라면 강사님 승인을 기다려 주세요 |
| Gemini API 키가 아직 없어요 | `GEMINI_API_KEY`와 `TEACHER_EMAILS`(내 이메일과 똑같이)를 넣고 다시 배포하거나, AI 설정에 키 넣기 |
| 오늘 AI 사용 횟수를 모두 썼어요 | 정상 동작이에요. 다음 날(한국 시간 자정) 다시 쓸 수 있어요 |
| 비밀번호 초기화… FIREBASE_SERVICE_ACCOUNT 설정이 필요해요 | 3번 설정 |

## 알아 두면 좋은 점

- **Google 계정으로 처음 로그인한 사람은 강사님 계정**이 됩니다. 수강생이 Google로 로그인해도 자기만의 빈 클래스가 생길 뿐, 다른 클래스는 볼 수 없어요.
- **승인을 거절**하면 그 번호로는 다시 가입할 수 없어요. (계정이 남아 있어서) 실수로 거절했다면 Firebase 콘솔 → Authentication → 사용자에서 `코드-번호@classapp.local` 계정을 삭제한 뒤 다시 가입하게 해 주세요.
- AI 호출이 실패해도 그날 사용 횟수는 1번 차감돼요.
- Google Analytics는 연결하지 않았어요. (수강생 앱에 추적 스크립트를 넣지 않기 위해)
