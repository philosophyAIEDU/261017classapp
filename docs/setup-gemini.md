# Gemini API 키 받고 앱에 넣기

AI 첨삭과 AI 튜터는 Google의 **Gemini**가 답합니다. Gemini를 쓰려면 **API 키**(AI를 쓸 수 있는 비밀 열쇠)가 필요해요.
키가 없어도 앱은 **샘플 AI**로 모든 기능이 동작하니, 먼저 둘러보고 나서 키를 넣어도 됩니다.

---

## 1. API 키 받기 (5분)

1. 브라우저에서 **https://aistudio.google.com** 에 들어갑니다.
2. 오른쪽 위 **로그인**을 눌러 Google 계정으로 로그인합니다.
   - 처음이라면 이용약관 동의 화면이 나와요. 내용을 읽고 동의합니다.
3. 왼쪽 메뉴(또는 오른쪽 위)에서 **Get API key**를 누릅니다.
4. **API 키 만들기(Create API key)** 버튼을 누릅니다.
   - 프로젝트를 고르라고 하면 기본으로 나오는 것을 그대로 선택하면 됩니다.
5. `AIza`로 시작하는 긴 글자가 나오면 오른쪽의 **복사** 버튼을 누릅니다.

> 🔐 **API 키는 비밀번호와 같아요.** 다른 사람에게 보내거나, 단톡방·게시판·GitHub에 올리지 마세요.
> 실수로 퍼졌다면 같은 화면에서 그 키를 **삭제**하고 새로 만드세요.

---

## 2. 앱에 키 넣기

1. 앱에 **강사님**으로 들어갑니다. (데모 모드라면 맨 위 **강사님으로 보기**)
2. 위쪽 메뉴에서 **AI 설정**을 누릅니다.
3. **API 키 붙여 넣기** 칸에 복사한 키를 붙여 넣고 **[키 저장하기]**를 누릅니다.
4. **[키가 동작하는지 확인]**을 누릅니다.
   - ✅ `키가 잘 동작해요!` → 성공
   - ❌ `API 키가 올바르지 않아요` → 키를 다시 복사해서 넣어 보세요. (앞뒤 공백, 일부만 복사된 경우가 많아요)
   - ❌ `AI 서버(Netlify Functions)가 켜져 있지 않아요` → 아래 "3. 어디서 실행해야 하나요?"를 보세요.
5. **어떤 AI를 쓸까요?**에서 **Gemini (진짜 AI)**를 고릅니다.
   화면 오른쪽 아래 작은 배지가 `Gemini AI`로 바뀌면 끝!

### 모델 고르기

같은 화면 아래에서 **과제 첨삭**과 **AI 튜터**에 쓸 모델을 따로 고를 수 있어요.

| 모델 | 특징 | 기본으로 쓰는 곳 |
| --- | --- | --- |
| `gemini-3.8-flash` | 꼼꼼하고 똑똑해요 | 과제 첨삭 |
| `gemini-3.5-flash-lite` | 빠르고 가벼워요 | AI 튜터 |

> 다른 모델을 쓰고 싶다면 `src/config/aiModels.ts`에 한 줄 추가하세요. 서버는 이 목록에 있는 모델만 허용합니다.

---

## 3. 어디서 실행해야 하나요?

AI는 브라우저가 Gemini에 직접 연결하지 않고, **우리 앱의 서버(Netlify Functions)**를 거쳐서 부릅니다. 그래야 안전하거든요.
그래서 서버가 함께 켜진 곳에서만 진짜 AI가 동작해요.

| 실행 방법 | 진짜 AI | 설명 |
| --- | --- | --- |
| Netlify에 배포한 주소 (`https://○○.netlify.app`) | ✅ | [deploy-netlify.md](./deploy-netlify.md) 참고 |
| 내 컴퓨터에서 `npm run dev:ai` → http://localhost:8888 | ✅ | 처음 한 번 `npm install -g netlify-cli` 필요 |
| 내 컴퓨터에서 `npm run dev` → http://localhost:5173 | ❌ | 화면만 켜져요. 샘플 AI로 연습할 때 |
| Netlify Drop(드래그앤드롭) 배포 | ❌ | 서버 함수가 올라가지 않아요 |

## 4. 키는 어디에 저장되나요? (꼭 읽어 주세요)

- 키는 **키를 넣은 그 브라우저에만** 저장됩니다. 다른 컴퓨터나 수강생 휴대폰에는 저장되지 않아요.
- AI를 부를 때마다 키가 **우리 앱 서버로만** 전달되고, 서버는 키를 **저장하거나 기록하지 않습니다**.
- 그래서 **키를 넣은 기기에서만 진짜 AI가 동작**합니다.
  - 수업 시연(한 기기에서 강사님·수강생 화면을 오가며 보여 주기)에는 그대로 쓰면 됩니다.
  - 수강생들이 각자 기기에서 진짜 AI를 쓰게 하려면 Firebase 모드 + 아래 "서버에 기본 키 넣기"를 쓰세요.
- 여러 사람이 쓰는 컴퓨터라면, 수업이 끝난 뒤 **AI 설정 → [키 지우기]**를 눌러 주세요.

### (선택) 서버에 기본 키 넣기

Netlify 환경변수 `GEMINI_API_KEY`에 키를 넣으면, **AI 설정에 키가 없는 기기(수강생 휴대폰)에서도** 그 키로 AI가 동작합니다.

- **Firebase 모드(추천)**: `TEACHER_EMAILS`에 내 Google 이메일을 함께 넣으세요. 서버가 로그인 토큰 → 승인된 구성원 → 하루 사용량(수강생 1명당 40번, 튜터 20번)을 확인한 뒤에만 키를 씁니다. → [setup-firebase.md](./setup-firebase.md)
- **로컬 모드**: 로그인 확인이 없어서 **배포 주소를 아는 누구나 그 키를 쓸 수 있어요.** 로컬 모드에서는 서버 키를 비워 두세요.

---

## 5. 요금과 데이터 정책

- Gemini API에는 **무료 티어**와 **유료 티어**가 있고, 하루·분당 사용량 한도가 있어요.
  한도를 넘으면 앱에 `지금 AI를 쓰는 사람이 많거나 사용량을 다 썼어요`라고 나옵니다.
- ⚠️ **티어마다 입력한 내용이 Google의 서비스 개선에 쓰일 수 있는지가 다릅니다.**
  수강생 글을 보내기 전에 Google AI Studio의 **최신 이용약관과 데이터 정책을 꼭 확인**하세요.
- **학원의 개인정보 처리방침**(미성년 수강생은 보호자 동의 등)도 확인하세요. 학교에서 쓴다면 학교·교육청 지침을 따르세요.
- 앱은 수강생에게 "이름, 전화번호, 주소 같은 개인정보는 쓰지 마세요"라는 안내를 항상 보여 줍니다.
