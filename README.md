# 나만의 AI 클래스앱 (교육자용 베이스 템플릿)

선생님의 루브릭으로 AI가 바로 첨삭해 주는 **과제방**, 매일 쌓는 **학습 루틴 인증**, 정답 대신 힌트를 주는 **AI 탐구 튜터**를 한 앱에 담았습니다.

> 지금은 **1단계(1주 차: 화면)** 완성 상태입니다. 인터넷·API 키 없이 이 컴퓨터에서 모든 기능을 체험할 수 있어요.
> 2단계(Gemini 연결), 3단계(Firebase), 4단계(배포)는 강의 진도에 맞춰 추가됩니다. 자세한 설치·배포 안내는 4단계에서 `docs/`에 정리합니다.

## 1단계 실행하기

1. [Node.js](https://nodejs.org) LTS 버전을 설치합니다.
2. 이 폴더에서 터미널을 열고 아래 두 줄을 차례로 입력합니다.
   ```bash
   npm install
   npm run dev
   ```
3. 화면에 나온 주소(보통 http://localhost:5173)를 브라우저에서 엽니다.
4. 첫 화면의 **"샘플 데이터로 바로 둘러보기"**에서 `선생님 화면` 또는 `학생 화면`을 누르세요.
   맨 위 검은 막대의 **"선생님으로 보기 / 학생으로 보기"** 버튼으로 언제든 바꿀 수 있습니다.

- 체험용 학생 로그인: 학급 코드 `DEMO26` · 번호 `1` · 비밀번호 `1234`
- 샘플을 처음 상태로 되돌리려면 맨 위 막대의 **샘플 초기화(↻)** 버튼을 누르세요.
- 화면 오른쪽 아래 작은 배지가 지금 모드를 알려 줍니다. (예: `로컬 저장 · 샘플 AI`)

## 내 수업에 맞게 바꾸기 (가장 먼저 볼 파일)

| 파일 | 바꿀 수 있는 것 |
| --- | --- |
| `src/config/appConfig.ts` ★ | 앱 이름, 기관 이름, 문구, `school`/`academy` 모드, 켜고 끌 기능, 색상, 튜터 하루 질문 횟수 |
| `src/prompts/rubricTemplates.ts` | 루브릭 예시 4종 (독서록·논설문·영작·과학 탐구 보고서) |
| `src/prompts/feedbackPrompt.ts` | AI 피드백 말투 (✏️ 바꿔도 되는 부분 / 🔒 안전 규칙 구분) |
| `src/prompts/tutorPrompt.ts` | 튜터 성격 예시 (🔒 안전 규칙은 교사도 끌 수 없음) |
| `.env` (`.env.example` 복사) | `VITE_DATA_MODE`, `VITE_AI_MODE`, `VITE_DEMO_MODE` |

## 그 밖의 명령

```bash
npm test          # 테스트 실행
npm run coverage  # 핵심 로직 커버리지 (80% 이상)
npm run build     # 배포용 빌드
```

## 안전·개인정보

- 학생은 실제 이메일·전화번호 없이 `학급코드 + 번호 + 이름 + 비밀번호`로 가입하고, 선생님이 승인해야 쓸 수 있어요.
- 과제·튜터 화면에는 "이름, 전화번호, 주소 같은 개인정보는 쓰지 마세요" 안내가 항상 보입니다.
- 1단계 로컬 모드의 데이터는 **이 브라우저에만** 저장되며 다른 기기와 공유되지 않습니다.
- 광고·외부 트래킹 스크립트는 없습니다.
