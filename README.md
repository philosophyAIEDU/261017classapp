# 나만의 AI 클래스앱 (교육자용 베이스 템플릿)

**레인보우 어학원**을 위한 AI 영어 클래스앱입니다. 강사님의 루브릭으로 AI가 바로 영작을 첨삭해 주는 **과제방**, 단어·듣기·쉐도잉을 매일 쌓는 **학습 루틴 인증**, 정답 대신 힌트를 주는 **AI 영어 튜터**를 한 앱에 담았습니다.

> 학교용으로 쓰려면 `src/config/appConfig.ts`에서 `mode`를 `'school'`로 바꾸세요. 호칭이 "학생·선생님·학급"으로 바뀝니다. → [docs/customize.md](docs/customize.md)
스마트폰·태블릿에서 쓰기 편하게 만들었고, 코딩을 몰라도 설정 파일 하나로 내 수업에 맞게 바꿀 수 있어요.

| 기능 | 수강생 | 강사님 |
| --- | --- | --- |
| ① AI 첨삭 과제방 | 영작을 내면 루브릭에 맞춘 피드백 카드, 고쳐 쓰기 2회 | 과제·루브릭 만들기(영어 일기·에세이·스피치·독후감 템플릿), AI 피드백 수정·승인, 코멘트 |
| ② 학습 루틴 인증 | 하루 1회 글+사진 인증, 달성률·잔디 달력·🔥 불꽃 배지 | 수강생 × 날짜 현황표, 오늘 미인증자 |
| ③ AI 영어 튜터 | 문법·표현을 힌트와 되묻기로 스스로 익히기 | 튜터 방·성격·지시문, 수강생별 질문 기록, 자주 나온 키워드 |
| 홈·포트폴리오·대시보드 | 오늘 할 일, 새 피드백 알림, 인쇄용 포트폴리오 | 오늘 요약, 수강생별 상세, CSV 다운로드, 입장 QR 인쇄 |

## 바로 실행해 보기

1. [Node.js](https://nodejs.org) **LTS** 버전을 설치합니다.
2. 앱 폴더에서 터미널(맥: 터미널, 윈도우: PowerShell)을 열고 차례로 입력합니다.
   ```bash
   npm install
   npm run dev
   ```
3. 브라우저에서 **http://localhost:5173** 을 엽니다.
4. 첫 화면의 **"샘플 데이터로 바로 둘러보기"**에서 `강사님 화면` 또는 `수강생 화면`을 누르세요.
   - 맨 위 검은 막대의 **강사님으로 보기 / 수강생으로 보기**로 언제든 바꿀 수 있어요.
   - 샘플을 처음 상태로 되돌리려면 같은 막대의 **↻ (샘플 초기화)**를 누르세요.
   - 체험용 수강생 로그인: 클래스 코드 `DEMO26` · 번호 `1` · 비밀번호 `1234`
5. 화면 오른쪽 아래 작은 배지가 지금 상태를 알려 줘요. 예: `로컬 저장 · 샘플 AI`

> 이렇게 켜면 **샘플 AI**(그럴듯한 연습용 답)로 모든 기능이 동작해요.
> 진짜 Gemini를 쓰려면 `npm run dev:ai`로 켜고 **AI 설정**에서 내 API 키를 넣으세요. → [docs/setup-gemini.md](docs/setup-gemini.md)

## 지금 버전에서 알아 둘 점

- **데이터는 각 브라우저에 저장됩니다(로컬 모드).** 한 기기에서 강사님·수강생 화면을 오가며 **시연**하기에 알맞아요.
  수강생들이 각자 기기로 함께 쓰려면 나중에 Firebase를 붙이면 됩니다. 화면 코드는 그대로 두고 저장소만 바꾸도록 설계되어 있어요.
- **Gemini API 키는 AI 설정에서 각자 넣습니다.** 키는 그 브라우저에만 저장되고, AI를 부를 때 우리 앱 서버(Netlify Functions)로만 전달돼요. 서버는 키를 저장·기록하지 않습니다.
- **Netlify Drop(드래그앤드롭) 배포는 AI가 동작하지 않습니다.** GitHub 연결로 배포하세요.

## 안전과 개인정보

- 수강생은 실제 이메일·전화번호 없이 `클래스 코드 + 번호 + 이름 + 비밀번호`로 가입하고, 강사님이 승인해야 쓸 수 있어요.
- 과제 제출·루틴 인증·튜터 화면에 **"이름, 전화번호, 주소 같은 개인정보는 쓰지 마세요"** 안내가 항상 보입니다.
- 모든 AI 피드백에 **"AI가 작성한 피드백입니다"**가 표시됩니다.
- 튜터의 안전 규칙(정답 바로 알려 주지 않기, 쉬운 말, 주제 밖 요청 되돌리기, 개인정보 묻지 않기)은 강사님도 끌 수 없습니다.
- AI 오류가 나면 수강생에게는 쉬운 한국어 안내만 보이고, 내부 오류 내용은 보이지 않아요.
- 광고와 외부 트래킹 스크립트는 없습니다.
- ⚠️ **Gemini API 무료/유료 티어의 데이터 활용 정책을 최신 약관에서 꼭 확인하세요.** 티어에 따라 입력 내용이 Google 서비스 개선에 쓰일 수 있습니다.
- ⚠️ **수강생 개인정보는 학원의 개인정보 처리방침과 관련 법령(미성년자는 보호자 동의 등)에 맞게 다뤄 주세요.** 학교에서 쓸 때는 학교·교육청 지침을 확인하세요.

## 명령어 모음

```bash
npm run dev       # 화면만 실행 (샘플 AI) → http://localhost:5173
npm run dev:ai    # AI 서버와 함께 실행 (진짜 Gemini) → http://localhost:8888
                  #   처음 한 번: npm install -g netlify-cli
npm test          # 테스트 실행
npm run coverage  # 핵심 로직 테스트 커버리지 (기준 80% 이상)
npm run build     # 배포용 빌드
```

## 폴더 구조 (궁금한 분만)

```
src/
  config/appConfig.ts       ★ 가장 먼저 고칠 파일 (이름·모드·기능·색·AI 기본값)
  config/aiModels.ts        고를 수 있는 Gemini 모델 목록
  prompts/                  AI 지시문·루브릭 템플릿 (✏️ 바꿔도 되는 부분 / 🔒 안전 규칙 구분)
  pages/student/            수강생 화면 (홈, 과제, 루틴, 튜터, 포트폴리오)
  pages/teacher/            교사 화면 (대시보드, 과제·루틴·튜터 관리, 구성원, 입장 QR, AI 설정)
  components/               버튼, 카드, 피드백 카드, 잔디 달력 같은 화면 조각
  repositories/             데이터 저장 (지금은 LocalRepository = 브라우저 저장)
  services/                 AI 연결 (MockAiClient = 샘플 AI, NetlifyAiClient = Gemini)
netlify/functions/          AI 서버 함수 feedback · tutor · check-key
docs/                       설명서
netlify.toml                Netlify 배포 설정
.env.example                환경 설정 예시 (복사해서 .env 로 사용)
```
